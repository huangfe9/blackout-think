Fix these defects found in code review. Keep everything else unchanged.

1. CRITICAL, app/main.py `_process_text_turn`: `build_turn_user_content` receives only prior history, so the model never sees the current utterance. Pass the current user text explicitly as its own `current_user_text` field in the payload and update TURN_SYSTEM_PROMPT to say that this is what to respond to. Add a test that inspects the mocked `responses.create` call and asserts the current text is in its input.

2. CRITICAL, app/static/index.html: `#page-black{display:flex}` overrides the `hidden` attribute, so the fixed black layer covers the start page on load. Add `[hidden]{display:none!important}`.

3. HIGH, index.html `stopAndSend`: `thinking` is set to false before the upload, so a key press during the request starts a second recording and turns can overlap. Keep `thinking` true until the reply has been received, including on every error path.

4. HIGH, index.html Esc handler: pressing Esc while recording never stops the microphone tracks or closes the AudioContext. Release them before calling finish. Also guard `finish` against running twice.

5. HIGH, index.html `startRecording`: on failure after getUserMedia succeeds (AudioContext or worklet errors), the microphone stream is left open. Release it on those paths.

6. MEDIUM, index.html mic button: it uses the browser SpeechRecognition API, which can send audio to a third party and does not use Meta models. Replace it: record with the same PCM/WAV pipeline, upload to a new `POST /api/transcribe` endpoint (same WAV validation and error envelope as turns, returns `{"transcript": str}`, no session needed), and fill the goal input. Click once to start, again to stop. Add tests for this endpoint.

7. MEDIUM, app/main.py: `FileResponse("app/static/index.html")` depends on the working directory. Resolve from `Path(__file__).parent`.

8. MEDIUM, app/main.py: FastAPI's default 422 response bypasses the error envelope. Add a RequestValidationError handler returning `{"error": {"code": "invalid_input", "message": ...}}` with status 400 and a test for it.

9. MEDIUM, index.html: the black screen must show only the dot. Make the hint fade out and be removed after 5 seconds.

10. README.md "How this project was built": delete "in one pass, without manual edits to the generated logic". State instead that Muse generated the code from the spec, a human-led review found defects, and the fixes were also generated by Muse from `spec/feedback_*.md`.
